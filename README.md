# criminal-intelligence-case-organizer.
The project I chose is the Criminal Intelligence Case Organizer.
This script is used by users to store data reports.
In order to run it you have to download python, once you open it go to file and create a new one, copy the code and paste it into the file, and on top it will say "run."
This is an example of something you can type once it is running:  Choose `1` to add a report.
2. Use fictional values such as:
   - Category: Observation
   - Fictional location: Unit B
   - Summary: A fictional report for testing the search feature
3. Choose `2` to view the saved report.
4. Choose `3` and search for `fictional`.
5. Choose `4` to exit.
